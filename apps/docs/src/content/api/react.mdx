The renderer behind neocord's JSX. It also works alone with plain discord.js. See [Using @neocord/react standalone](/docs/ui/standalone).

```pm
add @neocord/react react discord.js
```

Peer dependencies are `discord.js` `^14.28.0` and `react` `^19.3.0`. It runs on Node 22.12 or later and on Bun.

## Functions

### render

```ts
function render(node: ReactNode, options?: RenderOptions): RenderResult;

interface RenderOptions {
  live?: never;
}
```

Renders synchronously. It throws if anything suspends, and it throws if the tree has an `onClick` or `onSelect`, because those need a live root.

### renderAsync

```ts
function renderAsync(node: ReactNode): Promise<RenderResult>;
```

Waits for `<Suspense>` and `use()` to resolve, then serializes.

### renderModal

```ts
function renderModal(node: ReactElement, options?: Partial<ModalOptions>): ModalRenderResult;
function renderModal(node: ReactNode, options: ModalOptions): ModalRenderResult;

interface ModalOptions {
  customId: string;
  title: string;
}
```

Renders a modal synchronously, and throws if anything suspends. The custom id and title come from a root `Modal`, or from `options`.

### createLiveRoot

```ts
function createLiveRoot(options: LiveRootOptions): LiveRoot;

interface LiveRootOptions {
  sessionId: string;
  onUpdate?: (result: RenderResult) => unknown;
  onError?: (error: unknown) => unknown;
}

interface LiveRoot {
  render(node: ReactNode): void;
  readonly payload: RenderResult;
  readonly hasHandlers: boolean;
  dispatch(customId: string, event: unknown): Promise<boolean>;
  flush(): Promise<void>;
  settle(): Promise<void>;
  disableInteractive(): RenderResult;
  unmount(): void;
}
```

Creates a mounted tree for `onClick` and `onSelect`. See [Using @neocord/react standalone](/docs/ui/standalone).

### useLiveInteraction

```ts
function useLiveInteraction<E = LiveInteraction>(): E | null;

type LiveInteraction = ButtonInteraction | AnySelectMenuInteraction;
```

Returns the current event for components that render during a dispatch, and `null` otherwise.

### escapeMarkdown

```ts
function escapeMarkdown(text: string): string;
```

Escapes Discord markdown in user input, including headings, lists, masked links, quotes and subtext.

### buildCustomId

```ts
function buildCustomId(route: string, params?: Record<string, unknown>): string;
```

Re-exported from [`@neocord/routing`](/docs/api/routing#buildcustomid), along with the `RouteParams` type.

## Route types

The CLI augments `RegisteredRoutes` in `.neocord/types.d.ts`. With nothing registered, each route type is `string`.

```ts
interface RegisteredRoutes {}

type ButtonRoute = RegisteredRoutes extends { buttons: infer R extends string } ? R : string;
type SelectRoute = RegisteredRoutes extends { selects: infer R extends string } ? R : string;
type ModalRoute = RegisteredRoutes extends { modals: infer R extends string } ? R : string;

type RouteParamsRecord = Readonly<Record<string, ParamValue | readonly ParamValue[]>>;

type RouteAddress<R extends string> = string extends R
  ? { route: string; params?: RouteParamsRecord }
  : RouteTarget<R>;
```

`RouteAddress` requires `params` exactly when a route has params. See [Dynamic routes](/docs/routing/dynamic-routes).

### Button props

`ButtonProps<R>` is `InteractiveButtonProps<R> | LinkButtonProps | PremiumButtonProps`.

```ts
type InteractiveButtonStyle = "primary" | "secondary" | "success" | "danger";
type ButtonClickHandler = (event: ButtonInteraction) => unknown;
```

| Type | `style` | Addressed with |
| --- | --- | --- |
| `InteractiveButtonProps<R>` | `InteractiveButtonStyle`, optional | One of `route` and `params`, `customId`, or `onClick` |
| `LinkButtonProps` | `"link"` | `url` |
| `PremiumButtonProps` | `"premium"` | `skuId`, with no label, children or emoji |

Interactive and link buttons take `label`, `children` or `emoji`, as well as `disabled` and `id`. Premium buttons take `disabled` and `id`.

### Select props

Each select takes `placeholder`, `minValues`, `maxValues`, `disabled`, `required` and `id`, and is addressed with one of `route` and `params`, `customId`, or `onSelect`.

```ts
type SelectHandler<E> = (event: E) => unknown;
type SelectDefaultValue<T extends string> = string | { id: string; type: T };

interface OptionProps {
  label: string;
  value: string;
  description?: string;
  emoji?: EmojiInput;
  default?: boolean;
  children?: never;
}
```

| Type | Extra props |
| --- | --- |
| `StringSelectProps<R>` | `options`, or `Option` children |
| `UserSelectProps<R>` | `defaultValues?: readonly SelectDefaultValue<"user">[]` |
| `RoleSelectProps<R>` | `defaultValues?: readonly SelectDefaultValue<"role">[]` |
| `MentionableSelectProps<R>` | `defaultValues?: readonly { id: string; type: "user" \| "role" }[]` |
| `ChannelSelectProps<R>` | `defaultValues?: readonly SelectDefaultValue<"channel">[]`, `channelTypes?: readonly ChannelType[]` |
