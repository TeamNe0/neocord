@teamneo/neocord-react

The renderer behind neocord's JSX. It also works alone with plain discord.js. See Using @teamneo/neocord-react standalone.

Peer dependencies are discord.js ^14.28.0 and react ^19.3.0. It runs on Node 22.12 or later and on Bun.

Functions

render

Renders synchronously. It throws if anything suspends, and it throws if the tree has an onClick or onSelect, because those need a live root.

renderAsync

Waits for <Suspense> and use() to resolve, then serializes.

renderModal

Renders a modal synchronously, and throws if anything suspends. The custom id and title come from a root Modal, or from options.

createLiveRoot

Creates a mounted tree for onClick and onSelect. See Using @teamneo/neocord-react standalone.

useLiveInteraction

Returns the current event for components that render during a dispatch, and null otherwise.

escapeMarkdown

Escapes Discord markdown in user input, including headings, lists, masked links, quotes and subtext.

buildCustomId

Re-exported from @teamneo/neocord-routing, along with the RouteParams type.

Route types

The CLI augments RegisteredRoutes in .neocord/types.d.ts. With nothing registered, each route type is string.

RouteAddress requires params exactly when a route has params. See Dynamic routes.

Prop types

Shared

Layout props

Button props

ButtonProps<R> is InteractiveButtonProps<R> | LinkButtonProps | PremiumButtonProps.

TypestyleAddressed with
InteractiveButtonProps<R>InteractiveButtonStyle, optionalOne of route and params, customId, or onClick
LinkButtonProps"link"url
PremiumButtonProps"premium"skuId, with no label, children or emoji

Interactive and link buttons take label, children or emoji, as well as disabled and id. Premium buttons take disabled and id.

Select props

Each select takes placeholder, minValues, maxValues, disabled, required and id, and is addressed with one of route and params, customId, or onSelect.

TypeExtra props
StringSelectProps<R>options, or Option children
UserSelectProps<R>defaultValues?: readonly SelectDefaultValue<"user">[]
RoleSelectProps<R>defaultValues?: readonly SelectDefaultValue<"role">[]
MentionableSelectProps<R>defaultValues?: readonly { id: string; type: "user" | "role" }[]
ChannelSelectProps<R>defaultValues?: readonly SelectDefaultValue<"channel">[], channelTypes?: readonly ChannelType[]

Modal props

TypeProps
ModalProps<R>title, children, and either route with params or customId
TextInputPropscustomId, style, placeholder, required, minLength, maxLength, id, and either value or children
RadioGroupPropscustomId, required, id, and either options or children
CheckboxGroupPropscustomId, minValues, maxValues, required, id, and either options or children

Inline props

BoldProps, ItalicProps, UnderlineProps, StrikethroughProps, SpoilerProps, CodeProps, QuoteProps, SubtextProps and ListItemProps are aliases of InlineProps. UserMentionProps, RoleMentionProps and ChannelMentionProps are aliases of MentionProps.
