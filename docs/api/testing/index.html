neocord/testing

API reference for neocord/testing: run helpers, mocks and TestResult.

  • Run functions
  • TestResult

neocord/testing runs the real dispatch pipeline on fake interactions, with no gateway connection. For how to use it, read Testing.

Run functions

FunctionSignature
runCommand(definition, options?: RunCommandOptions) => Promise<TestResult>
runAutocomplete(definition, options: RunAutocompleteOptions) => Promise<AutocompleteResult>
runUserCommand(definition, options?: RunUserCommandOptions) => Promise<TestResult>
runMessageCommand(definition, options: RunMessageCommandOptions) => Promise<TestResult>
runButton(definition, options?: RunButtonOptions) => Promise<TestResult>
runSelect(definition, options: RunSelectOptions) => Promise<TestResult>
runModal(definition, options: RunModalOptions) => Promise<TestResult>
runEvent(definition, args, options?: RunBackgroundOptions) => Promise<BackgroundResult>
runTask(definition, options?: RunBackgroundOptions) => Promise<BackgroundResult>
renderModalOf(definition, options?: RenderModalOptions) => ModalRenderResult

TestResult

FieldTypeMeaning
repliesRenderResult[]Payloads sent as the first reply.
updatesRenderResult[]Payloads that updated the message a component is on.
followUpsRenderResult[]Payloads sent as follow-ups.
editsRenderResult[]Payloads that edited the reply.
modalModalRenderResult | nullThe modal that was shown.
deferredbooleanWhether the interaction was deferred.
deferredUpdatebooleanWhether a component update was deferred.
ephemeralbooleanWhether the response was ephemeral.
errorunknownThe first error the handler threw, or null.
textstringAll text from replies, updates, edits and follow-ups, joined by newlines.
liveLiveTestSession | nullThe open session, when the run set live: true and the handler started one.

LiveTestSession

MemberSignatureMeaning
click(label: string, options?: LiveEventOptions) => Promise<TestResult>Clicks the button with that label. Rejects if there is none, listing the labels it found.
select(values: readonly string[], options?: LiveSelectOptions) => Promise<TestResult>Chooses values in a select. Rejects if there is none.
close() => Promise<void>Ends the session.

LiveEventOptions is { user?: User; member?: GuildMember \| null }. LiveSelectOptions adds placeholder, which picks a select by its placeholder.

RunOptions

Every interaction run function accepts these.

OptionTypeMeaning
userUserThe user who ran it. Defaults to the member's user, or a new mockUser().
guildGuild | nullThe guild. null runs it outside a server.
memberGuildMember | nullThe member.
appAppContext | Record<string, unknown>The value of ctx.app. Defaults to an empty object.
middlewarereadonly TestMiddleware[]Middleware definitions, in order.
layoutsreadonly ComponentType<LayoutProps>[]Layout components, outermost first.
errorComponentType<ErrorProps>The error view.
loadingComponentTypeThe loading view.
modalsreadonly ModalDefinition[]Modals that ctx.showModal can open.
commandsreadonly CommandInfo[]The value of ctx.commands. Defaults to the commands in the run, which is only the command under test if there is one.
livebooleanKeeps a live session open on result.live. Close it with live.close().
loggerLoggerThe logger. Defaults to a silent one.
autoDeferAfternumber | falseMilliseconds before an automatic defer. Defaults to false.
hookApiHookCalled with the method name and payload of each fake API call. Throw from it to simulate a Discord error.

A guild and member are created for you when the definition sets guildOnly or non-empty permissions, and the member gets those permissions. Without them, and with no guild or member passed, the run has neither.

Options per function

FunctionExtra options
runCommandoptions: a partial object of resolved option values.
runAutocompleteoption: the option name, required. value: what the user typed, defaulting to an empty string.
runUserCommandtarget: User, defaulting to a new mockUser(). targetMember: GuildMember | null.
runMessageCommandtarget: Message, required.
runButtoncustomId, or params to build it from the route. message: the message the button is on.
runSelectEverything runButton takes, plus values (required), users, members, roles and channels.
runModalEverything runButton takes, plus values (required), a DefaultModalValues record.

BackgroundResult and RunBackgroundOptions

runEvent and runTask resolve to { error: unknown }, which is null if nothing was thrown. Their options are app and logger.

runEvent takes the client event's arguments as an array. runTask always runs the task once, on start.

AutocompleteResult

runAutocomplete resolves to { choices: OptionChoice[]; error: unknown }. error is null if the handler did not throw.

renderModalOf

Renders a modal to its payload. RenderModalOptions has app and logger, plus params, user, guild and member. Replying is not available while it renders, so any reply method on the context rejects.

Mocks

mockUser, mockMember, mockGuild, mockChannel and mockRole return real discord.js structures, so member.permissions and similar work. mockMessage returns a stub. Every option is optional, and ids default to generated values.

FunctionOptions
mockUserid, username, globalName, bot
mockGuildid, name, ownerId
mockRoleid, guild, name, permissions
mockMemberuser, guild, nickname, roles, permissions
mockChannelid, guild, name, type, which defaults to ChannelType.GuildText
mockMessageid, author, content, components, flags, hook, recording. flags defaults to Components V2, or to none when content is set.

Exported types

AutocompleteResult, BackgroundResult, LiveEventOptions, LiveSelectOptions, LiveTestSession, MockChannelOptions, MockGuildOptions, MockMemberOptions, MockMessageOptions, MockRoleOptions, MockUserOptions, RenderModalOptions, RunAutocompleteOptions, RunBackgroundOptions, RunButtonOptions, RunCommandOptions, RunMessageCommandOptions, RunModalOptions, RunOptions, RunSelectOptions, RunUserCommandOptions, TestMiddleware and TestResult.
