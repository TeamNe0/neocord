no-extra-exports

Allow only the default export, plus type exports, in files neocord routes.

  • Why
  • Messages
  • extra
  • exportAll
  • Incorrect
  • Correct
  • Turn it off
Rule idneocord/no-extra-exports
CategoryFile contracts
Severityerror in recommended, error in strict

Why

neocord only reads the default export of a routed file, so anything else exported from it has no effect on the route. Shared code belongs in a folder that starts with _, which is never routed.
