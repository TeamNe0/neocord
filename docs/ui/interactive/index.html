Interactive components

Buttons and selects go inside an ActionRow. A button can also be a Section accessory, and selects can also go inside a modal Label.

Addressing a handler

Every interactive component needs to say what handles it. There are three ways, and the types keep them mutually exclusive.

PropsMeaning
route and paramsAddresses a route file. route is checked against your files, and params is required exactly when the route has params. This is the preferred form.
customIdA raw custom id, as an escape hatch. It must be 1 to 100 characters and cannot start with ~.
onClick or onSelectRuns a function and makes the message a live session.

Using none or more than one throws, and so does params without route. The prefer-route-prop rule warns about literal customId values.

The custom id built from route and params must fit in 100 characters, or it throws a CustomIdError. Custom ids in one message must be unique. Two buttons with the same route and params throw "has a duplicate customId".

Emoji values

EmojiInput is a string or an object, and the same forms work on Button and Option.

ValueMeaning
"🌙"A Unicode emoji.
"<:party:123>", "<a:party:123>"A custom or animated emoji in Discord's format.
A string of 17 to 20 digitsA custom emoji id.
{ id, name, animated }A custom emoji as an object. It needs an id or a name.

Selects

All five selects share these props.

PropTypeMeaning
placeholderstringUp to 150 characters.
minValuesnumberFrom 0 to 25. Defaults to 1.
maxValuesnumberFrom 1 to 25. Defaults to 1. Must not be below minValues.
disabledbooleanDisables the select. Not allowed inside a modal.
requiredbooleanFor selects in a modal. With required not set to false, minValues must be at least 1 there.
route, paramsSelectRoute, route paramsAddresses a select file.
customIdstringA raw custom id.
onSelect(event) => unknownMakes a live session. event is typed for the select.
idnumberComponent id.

Inside a modal, a select uses customId as its field name, and onSelect is not available.

StringSelect

Choices you define. Provide them with Option children or an options array, not both.

PropTypeMeaning
optionsreadonly OptionProps[]The choices as data.
childrenReactNodeOption elements.

Limits: 1 to 25 options with unique values, and maxValues cannot exceed the number of options.

Option

One choice in a StringSelect, RadioGroup or CheckboxGroup. It throws anywhere else.

PropTypeMeaning
labelstring, required1 to 100 characters.
valuestring, required1 to 100 characters. Must be unique in its parent.
descriptionstringUp to 100 characters.
emojiEmojiInputStringSelect only. Radio and checkbox groups throw on it.
defaultbooleanSelected initially.

It takes no children.

UserSelect

Picks users. The handler reads ctx.users and ctx.members.

PropTypeMeaning
defaultValuesreadonly (string | { id: string; type: "user" })[]Preselected users. A string is an id.

RoleSelect

Picks roles. The handler reads ctx.roles.

PropTypeMeaning
defaultValuesreadonly (string | { id: string; type: "role" })[]Preselected roles. A string is an id.

MentionableSelect

Picks users and roles. The handler reads ctx.users, ctx.members and ctx.roles.

PropTypeMeaning
defaultValuesreadonly { id: string; type: "user" | "role" }[]Preselected users and roles. Plain strings throw, because the type cannot be inferred.

ChannelSelect

Picks channels. The handler reads ctx.channels.

PropTypeMeaning
defaultValuesreadonly (string | { id: string; type: "channel" })[]Preselected channels. A string is an id.
channelTypesreadonly ChannelType[]Limits which channels can be picked.

Limits on defaultValues, for all of the above: the count must be between minValues and maxValues, ids must be 1 to 20 characters, and each value must be unique. These selects take no children.

Handling the result

Write a button file or select file for routes. The select's type must match the component, because a RoleSelect sent to a route without type: "role" is rejected at dispatch as an unknown route.
