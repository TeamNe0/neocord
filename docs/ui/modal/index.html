Modal components

Modal, Label, TextInput, FileUpload, RadioGroup, CheckboxGroup and Checkbox, with every prop and limit.

These components build a modal, usually in the render function of a modal route. A modal holds one to five Label or TextDisplay children, and each Label wraps one form control.

Structure

Modal

The root of a modal. In a defineModal route you do not need it, because the route provides the custom id and title. Use it with renderModal directly.

PropTypeMeaning
titlestring, required1 to 45 characters.
route, paramsModalRoute, route paramsAddresses a modal route. Use this or customId.
customIdstringA raw custom id, 1 to 100 characters. Cannot start with ~.
childrenReactNodeLabel, TextDisplay, text and inline components.

Limits: 1 to 5 top-level children. It must be the only element at the root.

Modals cannot use onClick or onSelect, and renderModal is synchronous, so nothing inside may suspend.

Label

A title and description around one form control.

PropTypeMeaning
labelstring, required1 to 45 characters.
descriptionstringUp to 100 characters.
idnumberComponent id.
childrenReactNodeExactly one of TextInput, a select, FileUpload, RadioGroup, CheckboxGroup or Checkbox.

Field names

customId on a control is the field's name, and it becomes the key in ctx.values. With a schema, use field("name") from the render argument, which only accepts the schema's keys.

ControlValue in ctx.values
TextInputstring, omitted when left blank
Selects, CheckboxGroupstring[]
FileUploadstring[] of attachment ids. Read the files with ctx.fields.getUploadedFiles(name).
RadioGroupstring, omitted when nothing is chosen
Checkboxboolean

Controls

Control custom ids must be 1 to 100 characters, cannot start with ~, and must be unique in the modal.

TextInput

PropTypeMeaning
customIdstring, requiredField name.
style"short" | "paragraph"Defaults to short.
placeholderstringUp to 100 characters.
requiredbooleanWhether the field must be filled in.
minLengthnumberFrom 0 to 4000.
maxLengthnumberFrom 1 to 4000. Must not be below minLength.
valuestringInitial value, up to 4000 characters. Use this or children.
childrenReactNodeInitial value as text. Components inside throw.
idnumberComponent id.

FileUpload

PropTypeMeaning
customIdstring, requiredField name.
minValuesnumberFrom 0 to 10. Defaults to 1.
maxValuesnumberFrom 1 to 10. Defaults to 1. Must not be below minValues.
fileTypesstring[]1 to 10 entries: image, video, audio, or an extension with a leading dot such as .pdf.
requiredbooleanWith required not set to false, minValues must be at least 1.
idnumberComponent id.

It takes no children.

RadioGroup

Picks one option. Provide Option children or an options array, not both.

PropTypeMeaning
customIdstring, requiredField name.
optionsreadonly ModalOptionProps[]The options as data.
childrenReactNodeOption elements.
requiredbooleanWhether an option must be chosen.
idnumberComponent id.

Limits: 2 to 10 options with unique values, and at most one with default. Options cannot have an emoji.

CheckboxGroup

Picks several options. Provide Option children or an options array, not both.

PropTypeMeaning
customIdstring, requiredField name.
optionsreadonly ModalOptionProps[]The options as data.
childrenReactNodeOption elements.
minValuesnumberFrom 0 to the number of options. Defaults to 1.
maxValuesnumberFrom 1 to the number of options. Defaults to the number of options.
requiredbooleanWith required not set to false, minValues must be at least 1.
idnumberComponent id.

Limits: 1 to 10 options with unique values. Options cannot have an emoji.

Checkbox

A single on or off value.

PropTypeMeaning
customIdstring, requiredField name.
defaultbooleanWhether it starts checked.
idnumberComponent id.

It takes no children.

Option props in modals

ModalOptionProps is label, value, description and default, with the limits listed on Option.

Selects in modals

Any select works in a Label, with customId as the field name. disabled throws in a modal, and minValues must be at least 1 unless required is false. The prefer-route-prop rule does not report these, because modal fields need a customId.

Text in modals

Text and inline components can sit directly in a modal. They collapse into a TextDisplay that counts towards the limit of five.
