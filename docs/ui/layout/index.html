Layout components

Message, Container, Section, TextDisplay, Separator, ActionRow, MediaGallery, MediaItem, Thumbnail and File, with every prop and limit.

These components build the structure of a message. Most of them take an optional id, which is Discord's numeric component id. It must be an integer from 0 to 4294967295, and non-zero ids must be unique in the message.

Message structure

Message

Sets options for the whole message. It must be the only element at the root of the tree, and you only need it when you use one of its props.

PropTypeMeaning
ephemeralbooleanSets the ephemeral flag. Only you see the message.
allowedMentionsMessageMentionOptionsMention rules for this message. neocord's client default is { parse: [] }.
childrenReactNodeTop-level components, text and inline components.

Limits: at least one component, and at most 40 in total, counting nested ones. Inside another component, it throws "Message must be the root of the tree."

Container

A box with an optional accent colour, which replaces the role of an embed.

PropTypeMeaning
accentColornumber | "#rrggbb" | NamedColorAccent colour. A number must be from 0 to 16777215 (0xffffff).
spoilerbooleanHides the contents behind a spoiler. Defaults to false.
idnumberComponent id.
childrenReactNodeSection, TextDisplay, Separator, ActionRow, MediaGallery, File, text and inline components.

NamedColor is one of these:

NameValue
blurple#5865f2
green#57f287
yellow#fee75c
fuchsia#eb459e
red#ed4245
white#ffffff
black#000000

Limits: 1 to 40 children. A Container cannot hold a Container.

Section

Text with an accessory next to it.

PropTypeMeaning
accessoryReactNode, requiredExactly one Button or Thumbnail.
idnumberComponent id.
childrenReactNodeText blocks. Only TextDisplay, text and inline components.

Limits: 1 to 3 text blocks, and exactly one accessory. Adjacent text and inline elements collapse into one block.

TextDisplay

A block of markdown text. You only need it explicitly to keep two blocks apart or to set an id, because text collapses into one automatically.

PropTypeMeaning
idnumberComponent id.
childrenReactNodeText and inline components.

Limits: the rendered content must be 1 to 4000 characters. An empty TextDisplay throws, while empty collapsed text just produces nothing.

Separator

A gap between components, with an optional line.

PropTypeMeaning
dividerbooleanDraws a line. Defaults to true.
spacing"small" | "large"Size of the gap. Defaults to small.
idnumberComponent id.

It takes no children.

ActionRow

Holds buttons or a select.

PropTypeMeaning
idnumberComponent id.
childrenReactNodeInteractive components.

Limits: up to five buttons, or a single select. They cannot be mixed. Text inside it throws, and no-text-in-action-row reports it.

Media

The src prop on MediaItem, Thumbnail and File is explained on the Attachments page. A string is a URL or an attachment:// reference, and a Buffer or Uint8Array needs a name.

MediaGallery

A grid of images and videos.

PropTypeMeaning
itemsreadonly MediaItemProps[]The items as data. Use this or children, not both.
idnumberComponent id.
childrenReactNodeMediaItem elements.

Limits: 1 to 10 items. Anything other than MediaItem in its children throws.

MediaItem

One item in a MediaGallery. It must be inside one, and it does not count towards the 40 component limit.

PropTypeMeaning
srcstring | Buffer | Uint8Array, requiredURL, attachment:// reference, or bytes. A URL can be up to 2048 characters.
namestringAttachment file name. Required when src is binary.
descriptionstringAlt text, up to 1024 characters.
spoilerbooleanHides it behind a spoiler.

Thumbnail

An image used as a Section accessory. It is not valid anywhere else.

PropTypeMeaning
srcstring | Buffer | Uint8Array, requiredURL, attachment:// reference, or bytes. A URL can be up to 2048 characters.
namestringAttachment file name. Required when src is binary.
descriptionstringAlt text, up to 1024 characters.
spoilerbooleanHides it behind a spoiler.
idnumberComponent id.

File

An attached file shown as a download. This is the only media component that cannot take a plain URL.

PropTypeMeaning
srcstring | Buffer | Uint8Array, requiredBytes or an attachment:// reference.
namestringAttachment file name. Required when src is binary.
spoilerbooleanHides it behind a spoiler.
idnumberComponent id.

Limits: a URL throws File src must be a Buffer, a Uint8Array or an attachment://<filename> reference.

File shadows the global File type in any module that imports it.
